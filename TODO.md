## Структура папок, адрес, режим настройки

- [ ] Root — это `-root` или папка запуска, если флага нет.
- [ ] `data\`: база и лог. `-db` и `-log` с относительным путём считаются от root.
- [ ] `boot\`: `ipxe-shim.efi`, `ipxe.efi`, `wimboot`, `WinPE\boot.wim`,
  `agent\fogs-agent.exe`. По сети отдаётся только эта папка.
- [ ] Папка образов задаётся только в панели и не может лежать внутри `boot\`.
- [ ] Слушать `0.0.0.0`, `-ip` больше не обязателен, необязательный `-bind` для одного адреса.
- [ ] Один адрес для клиентов на сервер, настройка в панели со списком адресов машины.
  Если адрес один, выбирать его сами. Смена применяется без перезапуска.
- [ ] Режим настройки: панель работает всегда, а proxyDHCP, TFTP и HTTP для клиентов
  стартуют сами, когда заданы папка образов и адрес. Конфликт портов показывать в панели.
- [ ] Если папка образов пропала позже, службы не останавливать, только предупреждать.
- [ ] Привязать отправку ответа proxyDHCP к выбранному адресу: при двух сетевых картах
  broadcast может уйти не туда. Проверить на Windows на реальном ПК.
- [ ] Описать перенос файлов из старого `-root` в `boot\`.
