Настройки

Хранилище

Здесь сервер создаёт новые образы. Если папки нет, она будет создана. Созданные раньше образы остаются на своих местах.

Если компьютер после сети выпадает в настройки UEFI, попробуйте другой способ.

Папка EFI в папке сервера. Файлы отсюда доступны всем в сети без пароля, поэтому образы здесь хранить нельзя.

Сеть

По этому адресу компьютеры находят сервер при загрузке. Смена применяется сразу, но прерывает идущие задачи.

Можно оставить пустым. Клонировать и разворачивать такой ПК нельзя, пока образ не выбран.
